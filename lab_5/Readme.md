# Лабораторная работа №5: Обход бинарного дерева
### Вариативное задание:
-   7. Вывести «левый вид» дерева (первый узел на каждом уровне).
  
## Документация к функциям

- ### 1. preorder(root, result=None)
  - Основная функция, прямой обход дерева
    - Параметры:
      - root - корневой узел дерева
      - result - список для накопления результатов
    - Возвращает:
      - список значений узлов
- ### 2. inorder(root, result=None)
  - Основная функция, симметричный обход дерева
    - Параметры:
      - root - корневой узел дерева
      - result - список для накопления результатов
    - Возвращает:
      - список значений узлов
- ### 3. postorder(root, result=None)
  - Основная функция, обратный обход дерева
    - Параметры:
      - root - корневой узел дерева
      - result - список для накопления результатов
    - Возвращает:
      - список значений узлов
- ### 4. level_order(root)
  - Основная функция, обход дерева в ширину
    - Параметры:
      - root - корневой узел дерева
    - Возвращает:
      - список значений узлов
- ### 5. left_view(root)
  - Основная функция, возвращает левый вид дерева
    - Параметры:
      - root - корневой узел дерева
    - Возвращает:
      - список значений левых узлов
- ### 6. test_all_funcs(name,tree)
   - Вспомогательная функция, выводит результаты всех обходов для заданного дерева
    - Параметры:
      - name - название дерева
      - tree - корневой узел бинарного дерева
    - Возвращает:
      - ничего
