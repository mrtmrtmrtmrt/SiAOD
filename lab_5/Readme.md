# Лабораторная работа №2: История браузера


### Вариативные задания:

- **3.** Вывод истории в виде таблицы с выравниванием колонок
- **5.** Топ-N переходов (наиболее частые переходы между доменами)


### Выбор структуры данных

Двухсвязный список был выбран из-за:
- частого перехода вперёд/назад — O(1)
- постоянного добавлениие новой страницы — O(1) 

## Документация к функциям
- ### 1. add_page(self, url , flagged)
  - добавляет новую страницу в историю
  - параметры:
    - url (str) — адрес страницы
    - flagged (bool) — добавить в закладки
- ### 2. get_domain(self, url)
  - извлекает домен из адреса страницы (удаляет https://, www., и т.п)
  - параметры:
    - url (str) — адрес страницы
- ### 3. clear_history(self)
  - очищает историю браузера и выводит сообщение об этом
  - параметры:
    - None
- ### 4. navigation_forward(self)
    - переход на следующую страницу в истории
    - параметры:
      - None
- ### 5. navigation_backward(self)
    - переход на предыдущую страницу в истории
    - параметры:
      - None
- ### 6. domain_search(self, searched_domain)
  - ищет все страницы, в домене которых содержится указанная подстрока
  - параметры:
    - searched_domain (str) — искомый домен
- ### 7. history_in_table(self)
  - выводит всю историю браузера в виде форматированной таблицы
  - параметры:
    - None
- ### 8. top_by_clicks(self, n = 5)
  - выводит топ-n самых частых переходов между доменами
  - параметры:
    - n (int) — количество позиций в топе(по умолчанию: 5)
