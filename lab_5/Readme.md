# Лабораторная работа №5: Обход бинарного дерева
### Вариативное задание:
-   7. Вывести «левый вид» дерева (первый узел на каждом уровне).
  
## Документация к функциям

- ### 1. insert(root, value)
  - Основная функция, считывает сколько раз встречается каждое слово
    - Параметры:
      - text - строка, в которой происходит счёт
    - Возвращает:
      - freq - словарь, имеющий вид: слово -> количество его повторений
- ### 2. preorder(root, result=None)
  - Основная функция, выводит в отсортированном видео по убыванию **слово** и **количество его повторений**
    - Параметры:
      - freq - словарь из слов и количество их повторений
    - Возвращает:
      - Ничего
- ### 3. inorder(root, result=None)
  - Вспомогательная функция, преобразует текст в массив слов
    - Параметры:
      - text - строка для разбиения в массив
    - Возвращает:
      - Массив из слов
- ### 4. postorder(root, result=None)
  - Вспомогательная функция, преобразует текст в массив слов
    - Параметры:
      - text - строка для разбиения в массив
    - Возвращает:
      - Массив из слов
- ### 5. level_order(root)
  - Вспомогательная функция, преобразует текст в массив слов
    - Параметры:
      - text - строка для разбиения в массив
    - Возвращает:
      - Массив из слов
- ### 6. left_view(root)
  - Вспомогательная функция, преобразует текст в массив слов
    - Параметры:
      - text - строка для разбиения в массив
    - Возвращает:
      - Массив из слов
