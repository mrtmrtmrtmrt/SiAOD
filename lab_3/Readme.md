# Лабораторная работа №3: Очередь через два стека
### Вариативные задания:
  - 7. Подсчитать количество операций enqueue/dequeue
  
## Описание реализации функции dequeue для очереди из двух стеков
Для реализации удаления элемента из начала очереди потребовалось провести цикл, который работает пока в stack_in есть элементы, перекладывания из stack_in в stack_out в обратном порядке с помощью встроенной функции pop().
## Документация к фукнциям
- ### 1. init(self)
  - инициализация двух стеков и счётчиков: 
    - stack_in, stack_out,
    - count_enqueue, count_dequeue
- ### 2. enqueue(self, added_elem)
  - добавляет новый элемент в очередь(в stack_in)
  - параметры:
    - added_elem — элемент для добавления
- ### 3. dequeue(self)
  - Удаление первого элемента из очереди(перемещение в обратном порядке из stack_in в stack_out)
  - параметры:
    - Нету
- ### 4. front(self)
  - Просмотр первого элемента
  - параметры:
    - Нету
- ### 5. is_empty(self)
  - Вспомогательная функция для проверки на пустоту
  - параметры:
    - нету
- ### 6. size(self)
  - Вспомогательная функция для измерения двух стеков
- ### 7. count_info(self)
  - Выводит сколько раз были произведены операции enqueue и dequeue
